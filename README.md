## Project Description

**MyFirstGitProject** is a personal portfolio and introductory webpage created to showcase basic front-end web development skills alongside Git version control practices. 

The project features a sleek, modern glassmorphic interface built using semantic HTML5 and vanilla CSS3. It introduces the developer, highlights key technical competencies (HTML5, CSS3, JavaScript, Git & GitHub, C/C++, Data Structures), and provides direct links to the developer's GitHub profile and contact email.

### Key Highlights:
- **Clean Semantic Structure:** Built with valid HTML5 semantic tags.
- **Modern Responsive Design:** Crafted with responsive vanilla CSS, featuring glassmorphism, subtle glowing background accents, and smooth micro-interactions.
- **Git & GitHub Integration:** Demonstrates version control best practices, including initial repository setup, branching, committing, and pushing code to GitHub.

---

## Technologies Used

- **HTML5:** Page structure, semantic tags, and meta configuration.
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, animations, and responsive media queries.
- **Git:** Local version control (branching, staging, committing).
- **GitHub:** Remote repository hosting and collaboration.

## Git Commands Executed

```bash
# Initialize local Git repository
git init

# Check the status of working tree
git status

# Stage all files
git add .

# Create initial commit
git commit -m "Initial commit"

# Set default branch to main
git branch -M main

# Link local repository to remote GitHub repository
git remote add origin https://github.com/Somitsarkar2103/portfolio_2.git

# Push changes to remote repository on branch main
git push -u origin main
```
